Renkin builds a real, installable icon pack from your own choices — no PC, no account, offline. Pick icons from packs you already have, redraw or recolour them, then compile and sign the pack on-device and select it in your launcher.

Fork of <a href="https://codeberg.org/kaanelloed/Alembicons">Alembicons</a> by kaanelloed (formerly Iconeration), with its own direction on top.

<b>Features</b>

<ul><li>Source an icon from any installed icon pack, the app's own icon, or its name as text</li>
<li>Modify icons: path tracing, edge detection, colorize, background removal, vector editing</li>
<li>Icon shapes — crop any icon into Material You shapes (circle, squircle, pebble, …) or put it on a coloured shape plate</li>
<li>Text icons with custom text, letter case and any system font (or the bundled Arcticons Sans)</li>
<li>Import your own image per app — SVG included, rendered sharp or imported as editable vector paths</li>
<li>Themed (Material You) icon export</li>
<li>Profiles — several named icon sets, each with its own built pack, side by side</li>
<li>Profile sharing — export a profile as a file anyone can import as a new profile; icons from paid packs stay locked until that pack is installed on the importing device</li>
<li>Backup and restore — one file with every profile, setting, watch rule and upload</li>
<li>Icon watch — get notified when a followed pack adds an icon for one of your apps</li>
<li>Calendar day icons that rotate with the date</li></ul>
