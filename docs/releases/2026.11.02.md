### New

- **Follow wallpaper colours:** Turn any single icon into a glyph that recolours with your wallpaper, keep Material You pack icons following it with separate Primary and Secondary switches, and keep the app icon's Material You variant live. Statistics show how many of a profile's icons follow the wallpaper.
- **Online icons:** Browse Iconify sets grouped into categories, download whole sets for offline use, and pick from the built-in Tabler set. SVG imports keep linear and radial gradients and paths that have both a fill and a stroke.
- **Calendar and clock icons:** Native app calendar icons and alternate app icons are supported. Calendar day icons and live clocks keep their modifiers and Global Style, and the enlarged editor preview shows every day and time.
- **Pack preview grid:** The generated pack shows a searchable icon grid with a background switch. [#28](https://github.com/renkindevbugs/Renkin/issues/28)
- **Build animation:** Pack preview opens inside Renkin, and the icons dissolve into a golden galaxy that forms the Renkin Pack symbol while the pack builds.

### Improved

- A Motion setting chooses which animations play: icon flight, editor tab icons, build animation and attention pulses.
- Adjustable corner roundness for the squircle icon shape. [#31](https://github.com/renkindevbugs/Renkin/issues/31)
- Faster icon pack browsing and editor loading, smoother Pack preview scrolling, and lower memory use while building.
- Animated editor navigation icons, quieter edit recovery with a restore action on the home screen, and a clearer empty Create tab when no icon pack is installed.
- Renkin now requires Android 7.0 or newer.

### Fixed

- Pack builds work again on Android 9 and 10, and a failed build shows a readable report instead of a short message.
- One profile's pack icon no longer appears on other profiles' packs.
- Settings warns when the latest automatic backup failed and lets you choose the backup folder again.
- Icon watch keeps precise read failures and retries missing pack icons.
- Fewer crashes when drawing icons from installed packs.
