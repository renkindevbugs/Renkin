### New

- **More Global Style tools:** Customize shadows directly in the bottom panel while keeping icons visible, return to earlier looks through Apply history, and keep the global style while editing an individual icon. Bake a look into the icons to build further effects on top, with an option to undo the bake. Includes [#22](https://github.com/renkindevbugs/Renkin/issues/22).
- **Edit recovery:** Recover supported unfinished editor sessions and unsaved custom icons after Android closes Renkin. Supported saved modifier settings can also be restored for further editing.
- **Custom pack identity:** Choose each profile’s pack icon and package name. [#26](https://github.com/renkindevbugs/Renkin/issues/26)
- **Add more apps:** Include disabled, hidden or not-yet-installed apps in a profile. [#24](https://github.com/renkindevbugs/Renkin/issues/24)
- **Match app color:** Recolour a neutral logo using the original app icon’s background colour. [#18](https://github.com/renkindevbugs/Renkin/issues/18)
- **App icons for the whole pack:** Use Default, Material You or Monochrome app icons as the source for every app. [#12](https://github.com/renkindevbugs/Renkin/issues/12)
- **Reuse Renkin packs:** A Settings option makes packs from other profiles available as icon sources. [#25](https://github.com/renkindevbugs/Renkin/issues/25)
- **Native Shevery support:** Silent installs and updates work through the Shizuku installer option without a compatibility stub. [#27](https://github.com/renkindevbugs/Renkin/issues/27)

### Improved

- Choose Primary and Secondary icon sources together, with counts showing how many missing icons a secondary pack adds.
- Edit icons directly from Pack preview and try launcher masks in the enlarged editor preview. Preview masks do not change the exported artwork.
- Quickly reuse recent modifier presets from the icon editor.
- Refreshed startup and editor transitions, sticky Global Style section headings, clearer TalkBack feedback, and a screen that stays awake while building a pack.
- Added an app language selector in Settings. English is currently the only included language.
- Reduced memory use when loading installed app icons, large saved icons and backups.

### Fixed

- More reliable pack updates, signature-conflict handling and installer fallbacks, with clearer failure details and an option to save the built APK if installation fails. Includes [#23](https://github.com/renkindevbugs/Renkin/issues/23).
- Large saved icons can load without exceeding Android’s database row limits. [#19](https://github.com/renkindevbugs/Renkin/issues/19)
- Corrected adaptive icon sizes, Material You colour handling, shape backgrounds and vector scaling.
- Improved profile switching, backup validation and restoration, and preservation of edits during long operations.
- More reliable Icon watch saves, suggestion application and notification cleanup.
